Re.L 0.6.1, an unofficial Android app for reading ReliefWeb. Not affiliated with ReliefWeb or OCHA. Download the `.apk` file under **Assets**, below. It installs over 0.6.0 and keeps everything on your phone.

## Safer by default

This version follows a security review of the app. Nothing changes in how you read.

- **PDFs come from reliefweb.int only.** A file hosted elsewhere is not downloaded; the report offers to open it in your browser.
- **Secure connections only.** Images that asked for an unencrypted connection now use an encrypted one.
- **Restoring a backup** checks the file more strictly. A file that holds more than a library could is refused with a message.
- **Your data stays on your phone.** Android's cloud backup and phone-to-phone transfer no longer copy Re.L's data. Use Settings > Back up your library to move it.
- **Shared files are cleaned up.** Exports of your library or highlights no longer stay in the app's cache.
- **One User-Agent, `Re.L (Android)`,** with no version number, for every request.
