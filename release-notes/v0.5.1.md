Re.L 0.5.1, an unofficial Android app for reading ReliefWeb. Not affiliated with ReliefWeb or OCHA. Download the `.apk` file under **Assets**, below. It installs over 0.5.0 and keeps everything on your phone.

## Finding an organization

This changes "Search organizations", in Follow an organization and in the Filters of Search.

- **From 2 letters.** Acronyms such as HI or WV are now searched. Before, the search waited for a third letter.
- **By the start of a word.** "solidar" finds Solidarités International, with or without the accent. Every word you type must begin a word of the name.
- **The acronym first.** When what you type is an organization's acronym, that organization comes first.
- **Errors that say what went wrong.** A failed search now says why, for example "Couldn't search organizations (no connection)". A search that finds nothing says so.
- **For Humanity & Inclusion, type HI or humanity.** Re.L searches names as ReliefWeb writes them and doesn't translate them, so "humanité" won't find it.

**This search is new and still to be confirmed.** It is built from ReliefWeb's API documentation and hasn't been tried against ReliefWeb itself yet. If an organization you look for doesn't come up, please [open an issue](https://github.com/13w13/relief-reader/issues) with what you typed and the message on screen.
