# Security

## Report a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead: [report a vulnerability](https://github.com/13w13/relief-reader/security/advisories/new), or open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainer sees your report.

Please include:
- the app version, shown in Settings under About Re.L;
- what is affected and what an attacker could do;
- the steps to reproduce it.

Never include your appname or any other credential.

## What to expect

Re.L is a spare-time project. Reports are read, but there is no fixed timeline for a fix. Only the latest release gets security fixes.

## Scope

- **In scope:** the code in this repository and the APKs on its [Releases](https://github.com/13w13/relief-reader/releases) page.
- **Out of scope:** ReliefWeb and its API. Report problems there to the United Nations, under its [Responsible Disclosure Policy](https://unite.un.org/united-nations-responsible-disclosure-reporter-acknowledgment-policy).

## Install from this repository only

Every release is signed with the same key. Android refuses an update signed with another key, so a copy of Re.L from elsewhere can't replace yours unnoticed. Download Re.L only from https://github.com/13w13/relief-reader/releases.
